## Nginx в Docker на Windows: статический сайт

## О проекте очень кратко
Это практическое задание 4,

Его цель — развернуть на Windows контейнер с веб-сервером **Nginx**, который отдаёт статический HTML-сайт по адресу `http://localhost:8080`. 
Файлы сайта лежат в обычной папке на хосте: при правке файла и обновлении страницы в браузере изменения применяются в режиме онлайн, без перезапуска контейнера.

## Что было сделано
1) Был установлен **Docker Desktop** с использованием **WSL 2**
2) Была создана структура проекта с 3-мя основными моментами:
- `docker-compose.yml` — описание контейнера и его настроек
- `nginx.conf` — конфигурация веб-сервера Nginx
- `site/` — проект собственного сайта (файлы) 
3) Было отключено кэширование в Nginx (`sendfile off` и `Cache-Control "no-store"`), (чтобы браузер работал с актуальной версией проекта)

## Структура проекта
```
nginx-static/
├── docker-compose.yml   # описание контейнера
├── nginx.conf           # конфигурация nginx
├── README.md            # этот файл
└── site/                # файлы сайта (монтируются в контейнер)
    └── index.html
        etc...
```

## Запуск контейнера через:
 docker compose up -d
